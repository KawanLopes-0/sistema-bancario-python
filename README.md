# Sistema Bancário em Python

Sistema bancário simples desenvolvido em Python como parte do meu roadmap de estudos em programação.

## Funcionalidades

* Depositar valores;
* Sacar valores;
* Consultar saldo;
* Visualizar extrato bancário;
* Validar depósitos e saques com valores inválidos;
* Impedir saques superiores ao saldo disponível;
* Informar opções inválidas;
* Encerrar o sistema pelo menu.

## Tecnologias utilizadas

* Python 3
* Git
* GitHub

## Como executar

1. Tenha o Python instalado.
2. Clone este repositório ou baixe os arquivos.
3. Abra o terminal na pasta do projeto.
4. Execute:

```bash
python main.py
```
